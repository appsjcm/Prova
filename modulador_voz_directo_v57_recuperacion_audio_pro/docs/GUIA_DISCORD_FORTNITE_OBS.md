# Guía V44 - Mezclador Musical Pro

## Mezclador

La pestaña `Mezclador` permite equilibrar voz, instrumental y master final.

## Uso recomendado

1. Genera una canción en Canción Pro.
2. Abre Mezclador.
3. Prueba Equilibrado.
4. Si la letra no se entiende, usa Voz delante.
5. Si quieres practicar ritmo, usa Base fuerte.
6. Para grabar, usa Demo final.
7. Guarda proyecto JSON.

## Proyecto JSON

Permite guardar letra, voz, efectos y mezcla para continuar luego.

## Uso con Discord / Fortnite / OBS

En el modulador:

- Entrada: tu micrófono real.
- Salida: CABLE Input / VoiceMeeter Input.

En Discord/Fortnite/OBS:

- Micrófono: CABLE Output / VoiceMeeter Output.
