# Modulador de Voz en Directo V80 - Revisión Total Pro

## Novedad principal

Nueva pestaña `🧭 Consistencia / Consistency`.

V79 añade una auditoría visual para revisar si la interfaz mantiene una imagen premium coherente entre diseño, iconos, idioma, exportación, publicación y módulos principales.

## Incluye

- Nueva pestaña `🧭 Consistencia`.
- Auditoría de coherencia visual.
- Puntuación de consistencia 0-100.
- Modos de consistencia:
  - Premium equilibrado
  - Studio glass
  - Launch limpio
  - Minimal pro
- Botón para aplicar reglas de consistencia.
- Exportar informe en JSON/TXT.
- Exportar tablero visual en PNG.
- Nuevos assets en `assets/interface_consistency`.
- Nuevas traducciones ES/EN relacionadas con consistencia visual.

## Objetivo

Hacer que el programa se sienta más ordenado, coherente y premium, especialmente ahora que tiene muchas pestañas y módulos.
