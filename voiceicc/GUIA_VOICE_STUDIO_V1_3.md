# Guía Voice Studio V1.3

## Cadena recomendada

1. Puerta de ruido suave.
2. De-esser.
3. Enfoque vocal.
4. Proximidad moderada.
5. Nivel inteligente.
6. Compresión ligera.
7. Espacio moderno con ducking.

## Comparación A/B

- Ajusta una voz y pulsa **Guardar A**.
- Modifica los controles y pulsa **Guardar B**.
- Usa **Alternar A/B** mientras escuchas el directo o una prueba grabada.

Para una voz natural evita valores altos de pitch, robot, vibrato y radio.
